# Phase 9.5 审查结果

日期：2026-10-10。结论：本地资产开放导出与恢复的软件范围通过。APK 0.9.5 / versionCode 7 / Room schema 3；未启动 Phase 10。Phase 9 真机及长期演出验收仍未完成。

## 实现与权限

- 用户确认管理员显式导出母库和共享批注，不包含其他成员个人层；实现排除所有个人层，管理员自己的个人批注同样单独备份。
- 普通成员仅导出/恢复本人已保存批注，不开放原 PDF 导出。成员 ID、版本 ID、SHA-256 和源页保持原值，不按姓名替换身份，不自动迁移新版批注。
- 母库开放 ZIP/JSON 包含原 PDF、所有历史版本与 activeVersion、曲目/乐章/声部/页段、成员权限/分配、节目单、共享发布与冻结快照。不存在的编号/分类功能没有冒称已实现。
- “我的”提供备份与恢复；管理员母库导出有单独确认，恢复先预览再确认。首次空库可先恢复母库，无须先创建管理员。非空母库拒绝覆盖/合并，个人同内容重复恢复幂等、冲突全批拒绝。
- 导出经系统 content URI，先在私有目录完整生成和验证，再写所选位置并回读完整 hash。恢复先在隔离 Room 验证，再复制 PDF 到随机管理路径并事务提交；不覆盖既有数据，不依赖旧设备文件路径。

实现位于 app/src/main/java/com/ensemble/scorelibrary/backup/，仅增量接入现有导航、Hilt 和批注 manifest 校验；既有权限/分配/个人节目单继续通过 Domain 解析。没有新增 PDF 第三方库，使用 Android 原生 PdfRenderer。数据库实体、schema 和迁移未改变，sources/ 未修改。

## 审查发现与修复

1. 切换成员及 A→B→A 时旧异步结果可能回流：加入操作代次与身份绑定，旧响应不能发布预览/成功状态。
2. 恢复确认弹窗可能阻挡取消，以及预览后进程恢复可能一直等待：开始恢复时关闭弹窗，明确重新选择提示；保存选择器上下文，但不伪称进程中断后已完成。
3. 恶意数据可用保留成员 ID shared 混淆共享层：恢复关系校验明确拒绝该成员 ID，并补回归。
4. Java ZipFile 不自动验证全部条目 CRC：对 JSON、说明和 PDF 都显式检查 CRC32，并用仍可解析的 JSON 位翻转样本验证拒绝。SHA-256 同时检查 PDF 和确认前后整包一致性。
5. 测试初始化的清理返回值不符合 JUnit 要求、编译类型推断提示：修复后完整重跑，不将最初失败当通过。

同时检查路径穿越、重复/未知条目、字段白名单、数值类型、嵌套深度、格式版本、文件缺失/损坏、activeVersion 归属、页段、批注坐标/版本/所有权及冻结节目单一致性。取消验证不修改目标库；事务提交为原子不可取消边界，取消提示不保证提交已经撤回。恢复失败只删除本操作创建的文件。

## 未验收与限制

- 没有操作物理 MatePad；华为/OEM 文件选择器、外部云盘提供者、真实换机和长期演出待后续验证。模拟器换机不是物理设备验收。
- ZIP 未加密，持有文件者可读取；CRC/hash 是损坏检测，不是作者认证或签名。备份需放到独立安全位置，不宣传绝对防复制或永不丢失。
- 本地成员选择不是生产身份认证；当前权限是逻辑身份下的导出隔离，不能冒称商业账号安全。NAS/登录/多租户不在本批范围。
- 只包含已保存批注；既有未保存笔画/失败恢复等 UX 待办没有在本批解决。缓存任务、脚踏、登录设置、撤销栈及阅读会话不导出。
- 格式 1 只支持 schema 3；未来新增分类/编号或跨版本迁移须有格式演进和兼容测试，不静默导入未知字段。
- 大容量上限是安全保护，不是容量性能承诺。进程强杀、断电及文件系统故障可能留下临时/孤儿文件；本批事务回滚与正常取消测试不能替代这些验收。
- 外部导出中断可能留下不完整 ZIP，不算有效备份；恢复不会删除用户选中的外部文件。母库恢复拒绝非空库，尚不提供合并恢复或自动身份映射。

以上为公开边界，不阻塞当前明确的本地软件范围；不得将本结论扩展为完整 Phase 9、NAS 灾难恢复或商业安全通过。
