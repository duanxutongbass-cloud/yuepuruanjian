# Android 0.10.2：正式同步、平板反馈与 App 内更新

2026-10-16；versionCode 14，数据库 schema 5。用户授权在同一工作区继续编号 5，并加入六项平板反馈及编号 18 的 App 内更新。源码未提交或推送。

## 功能与使用

- 团队账号登录后获取本人授权清单，在账号独立的私有数据库和 PDF 目录入库。首次登录、回到前台及前台每 60 秒同步；失败可重试。下载核对身份、授权、版本、大小、SHA-256 和 PDF，再复核授权提交。撤权先从可见曲库移除；退出、切换账号和会话失效会隔离原账号数据。本机曲库保留。
- 开启批注时自动恢复适页，工具栏占用独立高度，谱页位于其下；印章改为固定高度的页内滚动面板，避免弹窗和页面尺寸反复变化。
- 节目单选曲增加编号、分类、声部列表和数量，支持编号、曲名、分类、乐器、作曲/改编及备注组合搜索和分类筛选。选择一首曲目一次即可关联其全部已有声部，未自动合并同名曲目。
- 编号导入仅在末尾三位曲目序号、曲名、分类全部一致时自动补充已有曲目；重复乐器和冲突继续阻止。管理员曲库支持分类、乐器/声部、PDF 有无筛选；既有自建文件夹保留。
- “我的 → 应用更新 → 检查新版本”提供下载和安装。下载与安装前核对包名、版本、大小、SHA-256、签名证书和系统兼容性。系统首次可能要求允许此 App 安装更新，之后由用户确认覆盖安装。首次 0.10.2 仍须手动覆盖安装，之后版本才可从 App 更新；无需卸载。

## 发布接口

NAS 0.10.2 添加只读 releases 挂载用于运维发布，已发布 APK 复制到私有数据卷的 app-releases。GET /v1/app-release 返回公开软件版本，GET /v1/app-release/apk 要求精确 If-Match；这两个接口无需账号。账号、曲库和 PDF 接口继续鉴权。

```text
python /app/server.py --data /data publish-app --apk /releases/yuepuruanjian-0.10.2-sync-feedback-update.apk --version-code 14 --version-name 0.10.2
```

服务端验证基本 APK 文件结构、大小及哈希，Android 安装端最终核对签名和应用标识。不得将个人 PDF 或账号文件放入 releases。
