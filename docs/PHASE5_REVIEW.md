## 实际实现

- 真实 PDF 上的手写、透明荧光、整条笔迹/符号橡皮、套索选择、移动、删除、撤销/重做。
- 颜色、粗细和音乐符号菜单。符号包含力度、渐强/渐弱文字、升降号；不是工具占位。
- 我的批注和共享层独立显示隐藏。管理员在曲库选择共享草稿进行编辑，普通成员只读取已发布共享内容。
- UUID 批注和发布记录；按 PDF 版本、源页索引与个人 ownerKey/共享层隔离。坐标使用 0..1 页面归一化值，由原生 PDF 页面变换映射到屏幕。
- Room 保存每次已完成编辑，修订号拒绝过期写入。文件数据库重开验证持久化。读写和发布前重新运行既有 Domain 权限/谱段解析，不以 UI 隐藏代替授权。
- 共享发布生成不可变页面发布记录，不原地覆盖旧记录。演出页由管理员确认锁定整场演出的已发布共享状态，未发布/没有批注的页固定为空。
- 演出快照包含当时的谱版本、binding/页段及启用节目单顺序清单。后续草稿和发布不改变快照；版本/谱段/节目单变化产生明确错误，不将旧批注映射到新谱。
- 演出中共享层只读，个人层仍独立可编辑。没有锁定的演出明确标为未锁定，不伪称已经冻结。
- 为共同验证共享流程，导入新增默认关闭的显式“同时授权当前管理员”；只为该曲目增加 scoped permission 和 assignment，角色本身不授予谱权限。

## 修复与审查

- 修复旧测试迁移注册不完整，重新验证旧库保留。
- 损坏批注的真实 Android 回归确实发现反复渲染失败；保留同一 scope 的错误状态，禁止绑定自动重试，只由用户明确重试，并在 PDF Loading 中保留工具栏错误布局。修复后原失败测试及新增 ViewModel 测试通过，渲染次数能稳定下来。
- 已锁定节目单禁止导入追加，事务回滚曲目/版本/授权并清理新文件；实际导入测试验证记录与文件集合保持原样。
- 固定批注栏和保存进度区域高度，避免 PDF Loading/Ready 导致 viewport 尺寸反复变化和重渲染。
- 阅读模式批注层不截获拖动；工具改变重启手势处理，避免阅读与写画同时执行。
- viewport 与位图变换尺寸不一致时不展示可输入旧帧，避免窗口切换瞬间写错坐标。
- 修订检查、busy Guard 和 scope/epoch 隔离避免重复操作、延迟保存或重新进入旧页覆盖当前会话。
- 管理员降级立即屏蔽缓存共享草稿，再刷新仓储权限；仓储也拒绝共享编辑/发布。
- 重试清除过期撤销历史，保存失败保留明确错误，不能显示虚假保存成功。
- 套索、移动、橡皮计算在后台；每页最多 2000 个对象、100000 点，单手势最多 4096 点。撤销/重做最多 20 步并限制累计点量，不无限保留历史。
- 快照只查询本场演出相关版本，按 500 个版本分组，避免加载整个曲库和 SQLite 参数超限；发布快照内容有明确容量上限。
- 普通 Pad 图层分段控件加最小尺寸，工具允许横向滚动；选中色块有边框，工具具有名称和提示。
