# Phase 7：演出模式与离线可靠性

状态：2026-10-09 本批次软件范围已通过，证据与限制见 PHASE7_REVIEW。基于 Phase 1–6，不重建、不进入完整管理/NAS/商业版。

- 正式演出入场前检查 Domain 完整个人节目单的所有本地 PDF、hash、版本、页段和每页个人/共享批注，提前发现后续曲目缺谱与损坏。
- 正式节目单演出要求管理员已锁定共享批注快照，不能把未冻结的排练当成稳定演出；未锁定仍可普通阅读及跨曲排练。单曲阅读的专注模式不要求节目单快照。
- 检查过程有进度、可取消，不积累按键；失败不进入正式演出，不跳曲、不换版本、不自动扩大授权。
- 正式演出隐藏编辑、保持屏幕常亮；离开后恢复。配置/实例恢复必须重新检查，不把保存的布尔值当就绪证明。
- 断网不阻塞本地就绪内容；每页原生渲染继续校验打开文件，入场检查不代替运行期错误保护。当前是已导入本地内容，不虚构下载/NAS 缓存能力。
- 复用既有 Domain、锁定快照和 HID 连续游标；错误、取消、成员变化、缺失末曲、后页批注损坏必须有测试。
- 本批次检查上限 10,000 个授权页；大规模查询/预加载、复杂 PDF 长时性能与实际无线硬件仍待 Phase 9 验收。

实际构建、完整测试、Lint 和普通/大 Pad 真实截图已完成；不替代物理硬件或长期性能验收。
