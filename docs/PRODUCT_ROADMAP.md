### Phase 10.2：NAS 单乐团服务

- 实现真实身份认证、设备注册、角色与逐文件鉴权、原 PDF/版本存储、发布和成员专属变更清单、管理员操作审计及独立备份。
- 服务端是权限与分发的权威来源，不把完整 NAS 共享目录同步到所有成员，也不把当前本地成员选择当生产登录。
- 未授权声部文件不得下发。如果多个声部绑定同一母 PDF 的不同页段，必须提供独立声部文件或服务端生成授权分谱；单纯过滤列表/显示页段不合格。分谱身份和原版本/源页映射须稳定，不能导致批注错页或错误迁移。
- 母库管理权限、PDF 分发权限、个人批注读取/备份权限分别审查，不通过管理员 role 自动越权。
- 安全入口、文件完整性、数据库/文件一致备份和实际恢复需有证据；本地服务测试不能冒称 DS720+ 已部署或公网安全已验收。

### Phase 10.3：Android 授权自动同步

- 发布入库后自动获取当前成员获准文件；节目单负责演奏顺序，不触发首次分发。加入完整性校验、中断/失败重试、版本更新、明确待同步/已同步/可离线状态；管理员应能区分上传成功、发布完成和七台设备真正同步完成。
- 设备仅保存该成员获准的分谱，不下载其他声部母文件；真实 HTTP/文件 ID 越权拒绝和缓存隔离均须验证，继续复用 Domain 权限/分配/节目单解析。
- 在线收到撤权后停止后续分发并按冻结策略处理本地缓存；断网期间已取得文件无法保证即时撤回，更不能承诺绝对防复制。
- 已同步授权谱、批注和节目单断网仍可演奏，不依赖实时登录校验才能翻页；个人批注离线持久化，联网后按明确策略备份/同步，多设备冲突不得静默覆盖，撤权后的个人数据保留/恢复边界须明确。
- 版本替换与回滚不得串声部、读旧文件或静默丢批注；不自动把旧版批注迁入新版。

### Phase 10.4：七人封闭试运行

必须有可重复证据，而非口头确认：

1. 七人预下载后 NAS 断电且设备全程断网，仍能搜索、阅读、翻页、使用节目单和查看/新增批注。
2. 修改请求、猜文件链接或使用他人成员/文件 ID 无法取得未授权文件或密钥，成员缓存中不存在其他声部文件。
3. 发布新曲后授权设备自动收到正确分谱，未授权设备没有文件；节目单不承担首次分发。
4. 联网撤权停止分发并执行缓存策略，离线即时撤销的不可保证边界明确记录。
5. 模拟停服，从独立完整备份恢复母库与获准批注元数据，不依赖专有平台服务器。
6. 实际重装/换机恢复后核对曲目、PDF、版本、批注和节目单；成员重新授权后只重建自己的获准库。
7. 传输中断、重复上传、错声部发布及版本回滚不泄露内容、不静默丢批注。

同时完成全团真实排练、性能与安全检查；10.2/10.3 单端测试通过不能替代本阶段，也不能自动宣布 Phase 10 整体通过。

## 全局产品边界

- 首批用户为现有七人乐团。近期目标为 Windows 管理工具 + DS720+ 轻量单团队服务 + 原生 Android 演奏端；不是公开大规模云平台，不改回 PWA。
- 核心方向：离线能演出、停服能取谱、团队按权限分发。曲谱是用户资产，但离线已取得的文件技术上不能保证绝对不可复制，不能宣传“永远不丢”或“绝对防复制”。
- 不经营来源不明的公共曲谱库；用户导入内容应有合法使用权。用户关于其他软件的服务经历仅作为需求来源，未经独立证据不宣传停运原因或其他人的损失。
- 未决项由 PHASE10_0_REQUIREMENTS 集中记录：临时替补期限、跨设备冲突细则、私人灾备同意与密钥、具体外网入口及 NAS 条件。成员原 PDF 导出沿用已确认的暂不开放规则；新增水印策略须另行确认。Windows 无旧工具、自由维护成员/声部及流水号超过 999 自动扩位已确认，不再列为未知。水印不能代替逐文件鉴权。
