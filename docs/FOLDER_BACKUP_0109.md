# 编号 9 文件夹与封面备份（0.10.9 已发布）

当前线上 App 0.10.9（21）、NAS 后端 0.10.7。本项补齐 personal-library-folders 本机偏好不在旧母库/个人批注 ZIP 中的缺口，保留现有偏好键和曲目身份，不修改旧资产格式、原 PDF 或编号。文件夹跨设备自动同步属于下一项编号 10，本批不冒充已同步到 NAS。

## 使用

在曲库文件夹栏点“文件夹备份”，可导出或选择 ZIP，预览后明确确认恢复。团队账号也可新建/编辑个人文件夹和选择封面。该 ZIP 与母库/个人批注 ZIP 分开，需本人保存；恢复文件夹后，原曲谱仍须恢复原库或由 NAS 授权下载。预览列出新增、相同、缺失引用与冲突，有冲突时不能确认，完全相同记录可重复恢复，既有文件夹保留。

## 格式与恢复规则

- 独立开放 ZIP：仅 manifest.json 和 README.txt；UTF-8，format=ensemble-score-folders、formatVersion=1、owner、space、createdAtEpochMillis、folders、pieceReferences。space 为 local 或稳定的 team:账号曲库身份，不包含凭据。图片封面为既有 PNG Base64，乐谱封面保存原 pieceId；不复制乐谱内容，不增加授权。
- 最多 100 文件夹，每个名称 100 字以内/最多 10000 曲目引用，沿用原 8 MiB 文件夹 JSON 上限；清单最多 10 MiB、ZIP 最多 12 MiB、README 最多 64 KiB。图片最多 512 KiB、512×512，核对 PNG 标识、Base64、尺寸与实际解码。ZIP 中央目录、条目 CRC、长度和声明条目均校验，拒绝重复/额外/路径条目、未知字段和异常类型。
- 仅同一成员/同一曲库恢复，团队身份与离线核验期限必须有效。预览绑定源文件 SHA-256 和当前本机偏好指纹。新增记录合并，完全相同记录跳过；同 ID 内容冲突拒绝整次恢复，不覆盖本机。预览后源或本机变化要求重新预览。
- 保留原 pieceId，不按同名或编号替换。当前同 ID 曲目的序号不符时拒绝；缺失/未授权曲目引用保留但不能因此阅读，预览给出数量。原始 PDF、版本、批注与授权表不写入。
- ZIP 未加密，CRC/SHA-256 证明完整性而非作者身份；仅导出本人主动选择的保存位置。取消/中断的导出不能作为有效备份，导出必须回读全文件哈希一致才提示成功。
