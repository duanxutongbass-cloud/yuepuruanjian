# 0.9.9：阅读、批注、曲库和节目单

本次修改对应平板使用中反馈的七个问题。

## 书写与音乐符号

正常批注保存不再显示动态进度或增加提示行。阅读工具改为覆盖在谱页上，展开/收起工具、书写和保存不会改变 PDF 视口尺寸。笔迹使用可增量更新的点列表，读取触控事件提供的历史采样点；完成的笔画立即进入可见批注数据，后台保存失败仍保留重试入口。身份、源页或尺寸改变时继续取消未完成笔画，保留原有保存和权限检查。

点击主工具栏的「音乐符号」直接打开预制符号面板，按力度、渐变、变音、弓法、奏法、速度、反复提示分组。面板预览和谱页盖章使用同一个绘制函数。选择后点谱页放置，可重复使用；无需识别手写内容。现有批注符号继续可读。

## 全屏阅读

新打开曲谱默认全屏，隐藏应用顶部栏、系统栏、页码、声部文字和工具。普通阅读、节目单的「打开演出谱」均使用完整视口显示单张谱页；进入单曲专注/演出模式也自动隐藏工具。PDF 自身的白边和不同屏幕比例造成的留白仍遵循整页适配，保持乐谱比例。

轻点谱页显示覆盖工具；点「全屏看谱」收起。系统返回先显示工具，再返回列表；工具里的返回按钮直接离开阅读。未保存批注仍须选择留下重试或保留在当前进程内离开。出现文件/权限/保存错误时显示必要的错误入口。

## 个人分类文件夹

曲库增加自由命名的个人文件夹，可编辑名称、加入/移出曲目、删除文件夹；同一曲目可加入多个文件夹。删除文件夹不删除 PDF、曲目或批注。这些文件夹与整理器文件名中的分类独立，适合个人排练和收藏整理。

封面可通过系统选择器上传图片，或选用曲目默认声部的乐谱首页。图片在后台读取并缩小后存入本地；乐谱封面只保存曲目引用，显示时重新检查当前成员权限、版本和文件，撤销权限后停止显示。没有默认声部、授权不足或文件不可用时显示文件夹图标。横向列表仅加载可见文件夹的封面。

文件夹按成员隔离，保存在本机应用私有设置，覆盖安装会保留。0.9.9 当时母库/个人批注 ZIP 和 HTTP 测试同步不包含文件夹/封面。**0.10.9 已新增独立本人文件夹与封面 ZIP 备份**，见 [使用与验证](FOLDER_BACKUP_0109.md)；旧资产 ZIP 保持原范围。**0.10.10 已接入本人账号 NAS 跨设备同步**，支持离线保留、重开重试和双方冲突选择，见 [同步使用与验证](FOLDER_SYNC_0110.md)。未成功上传的离线修改仍只在原设备，卸载/清除前需主动导出并校验自己的备份。

## 节目单可见范围

管理员编辑节目单时可启用「指定可见成员 / 声部」，选择具体成员，或选择成员的默认声部；两者取并集。取消限制则所有成员可见。启用限制但没有选择任何成员/声部时，普通成员不可见，管理员仍可在管理中编辑。

这里的声部指成员设置中的默认声部。可见范围控制节目单列表及直接打开请求，**不授予曲谱访问权**；每张演出谱仍按原有成员声部授权和曲目分配解析。管理员的管理权限也不会自动授予阅读声部。

## 编号和元数据

曲库和管理员曲目列表将已有整理器编号放在标题前；小字显示分类与声部/乐器。曲库搜索增加乐器匹配，节目项选择器显示编号和分类。无编号旧记录不编造新编号，原 PDF 和原始文件引用保留。

## 数据升级与检查

Room 数据库升级至 5，4→5 只增加节目单的两个可见范围字段，旧节目单默认为不限制。原编号/分类迁移及批注数据保留。新备份使用格式 3 / 数据库 5，继续接收格式 1 / 数据库 3 和格式 2 / 数据库 4；旧格式补入空可见范围。导入时验证成员/声部引用。旧版应用与现有 local-manager 原型不能消费新的格式 3 备份。
