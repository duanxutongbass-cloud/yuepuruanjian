# Pad 产品设计

## 设备与布局

- 优先 20–27 英寸 Android 竖屏大 Pad，同时兼容普通 Android Pad。
- 按可用窗口 dp / Window Size 分档，不依赖物理英寸、设备型号或固定 px。必须处理旋转、窗口变化和有限高度。
- 当前断点：小于 600 dp 单列；600–839 dp 普通 Pad；840–1199 dp 扩展分栏；1200 dp 及以上大 Pad。
- 普通内容居中，按页面采用单列/网格/分栏，当前内容上限 1440 dp。标题、列表和工具保持合理密度，不按屏幕比例放大字体。
- PDF 与演出主要内容不受普通页面最大宽度限制，使用可用阅读空间。

## 导航与状态

- 2026-10-14 第三版目标经用户视觉审核纠正：整体为低饱和深色工作台、窄侧导航、左侧曲目列表及选中态、右侧大型白色真实授权 PDF 谱页，顶部搜索与当前成员。白色指乐谱纸面，不是白色曲目卡片；浅色网格切片未通过视觉审核。窄屏允许响应式单列。实施与附件读取阻塞见 ANDROID_PAPER_UI_REVIEW，不能把目标当已完成。管理继续并入“我的”，仅管理员可见；空库可创建管理员。
- 曲库有管理员导入入口，节目单有新建入口，详情有编辑入口；原地打开既有表单，不要求先切管理标签。成员与声部授权提供全部曲目的全局声部授权，不用逐曲重复勾选；例外权限及实际演奏分配仍独立。
- 曲谱库检索消费既有 Domain 曲目目录，成员变化清空查询及预览；同一成员打开阅读器再返回保留首页查询和选中项。离开曲库、暂停、错误及权限变更不保留可见旧谱页。预览必须由 Domain 解析当前个人声部，并验证本地文件、版本 hash 和源页段；缺文件或无权限显示真实状态，不虚构缩略图、编号、页数或本地可用性。目录标题可见规则沿用基线，搜索不是授权边界。打开阅读器仍重新走 Domain；保存批注在阅读器显示，预览不编辑批注。
- 看谱和演出隐藏普通侧边/底部导航；返回普通页面恢复导航。普通全屏与正式演出独立：全屏隐藏应用顶部、页码、工具及系统栏，只显示谱面与原有可见批注；点按退出全屏恢复操作栏，系统返回先退出全屏，不直接离开曲谱。全屏不要求冻结节目单。
- 根导航保持 singleTop、保存/恢复返回栈；配置变化不能丢失当前成员、阅读页和合理会话状态。
- Loading / Empty / Error / Offline / FileMissing 及 PDF 损坏、版本缺失、页段越界必须区分；离线不等于本地不可读。
- 阅读/演出 UI 仅展示并触发操作，权限、默认声部、单曲覆盖、节目单解析均消费 Domain。未授权声部名称、谱和批注不可泄露。
- 管理目录是单独的管理员元数据权限，供编辑曲目、声部、版本、成员授权及节目单；普通成员不能读取。管理员在此看到可管理的声部名称，不等于获得 PDF 或他人个人批注权限；进入看谱仍按 Domain 授权。实际分配候选与当前演奏结果消费 Domain，不由管理 UI 重写选谱。
- 管理列表/详情按可用宽度 840 dp 分栏；较窄窗口进入详情后保留返回列表。新增和编辑采用可滚动表单，归档记录显式显示/恢复。过期表单禁止保存，PDF 换版/回滚需明确确认批注按版本隔离。

## 视觉与输入

- 风格高级、克制、专业工具化；不是营销页或简单放大的手机界面。
- 工具用图标按钮和可访问名称/提示；颜色用色块，互斥模式用分段控件，显示隐藏用开关/复选框，数值用滑杆或输入。
- 批注工具不得遮住谱面关键内容或挤压成无法使用的固定宽度栏；较窄窗口允许工具横向滚动或折叠。
- 笔、触控与阅读拖动应有清晰模式，不能同一手势同时写字、套索和滚动。
- 阅读/全屏下左滑下一页、右滑上一页，方向及位移门槛防误触；写画/套索期间不滑动翻页。放大后拖动移动页面、不翻页；双指缩放限定 1–4 倍，缩放重新原生渲染可见窗口，批注共享同一 PDF 坐标变换。
- 编辑锁定用于防误触，随时可解除，按成员保留会话状态，不删除批注，也不授予共享层编辑权。冻结本场共享版本是另一个明确确认的不可变历史操作，不因解除编辑锁定覆盖旧快照。
- 套索圈选后直接进入移动，显示选中数量与移动/删除动作。音乐符号使用显眼的独立分类面板，保留预设插入语义，不称为手写识别。
- 长文本、按钮、菜单、状态和字号不得重叠或裁切。所有主要状态在普通/大 Pad 尺寸检查。
- PDF 原生分辨率渲染；批注叠加按同一页面变换，禁止把屏幕像素当永久坐标。

各阶段功能验收维护于对应 PHASEx_REQUIREMENTS；本文件只维护通用 Pad 设计规则，不重复阶段业务要求。
