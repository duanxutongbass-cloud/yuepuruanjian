# Phase 9：真机与性能验收

状态：2026-10-09 已启动，进行中、未通过。用户最新决定暂时不做真机，继续自动测试/模拟器验证，不继续安装驱动或排查 USB。设备为用户报告的 MatePad Pro 2021、HarmonyOS 4.2.0.213，Windows 识别 WGR-W09；尚无授权 ADB 真机实测。大 Pad、笔、脚踏与长期测试不能由模拟器代替。

## 验收范围

- 普通 Android Pad 和重点 20–27 英寸竖屏大 Pad 分别记录型号、系统/API、实际窗口 dp/密度和 APK 版本。检查单栏/分栏、窗口变化、系统导航区、软键盘、长文本和主要状态。
- 使用真实 PDF，至少包含普通谱、多页/不同尺寸谱、复杂或扫描大文件；记录文件 hash/字节数/页数，不在报告中公开个人曲谱。确认绑定页段、当前版本、换版/回滚与旧批注隔离。
- 实际触控/笔输入检查批注定位、保存、套索/擦除与阅读拖动互斥。记录笔型号及操作系统支持情况；没有笔则待验，不声称完成。
- 实际 HID 脚踏测试系统配对、学习/持久化、去抖、长按、断开/重连、后台/恢复、多曲正反翻页和禁止编辑期间翻页。虚拟 KeyEvent 只证明软件路径。
- 断网个人节目单准备、冻结共享层、常亮、缺文件/损坏/撤权/版本变化停读、恢复重新检查；离线不绕过授权。
- 连续阅读、翻页、Fit Width 滚动/模式切换、跨曲、旋转与进后台。记录首屏/翻页耗时、内存/PSS、帧数据、文件句柄和异常；明确测试时长、次数、PDF/数据规模、温度/供电环境。
- 大数据量 Room/Domain 和管理目录的查询/投影开销需要真实记录，按结果优化而非提前宣称上限。Phase 8 全表快照风险在此追踪。
- 长时间验收至少完成一场真实排练或等长持续操作，记录实际时长和负载；具体性能产品阈值尚未冻结，观察值不能冒充商业 SLA。无崩溃/ANR、读错谱、越权、丢批注或持续资源增长是必要条件，但不足以单独证明完整通过。

## 数据安全

现有 connectedDebugAndroidTest 含测试数据布置/清理，Gradle UTP 可能重装/卸载测试目标；禁止直接对有用户资料的物理 Pad 执行完整套件。自动回归用隔离模拟器。要在真机跑自动测试，须先建立与用户应用独立的验收包/数据环境，或明确允许使用空测试设备；未得到授权不清库、不卸载、不修改系统密度。

初次真机只读取设备和当前包信息、记录结果。覆盖安装前检查签名/版本与用户数据保留需求，不为解决签名冲突卸载旧包。截图、曲谱导出、完整日志可能包含个人资料，需按实际任务明确收集范围。

## 工具与证据

- `tools/Collect-PadDiagnostics.ps1`：显式指定 serial 和标签；记录设备/应用信息以及有限次数 meminfo/gfxinfo 采样。不安装/卸载、清数据、修改设置、截图或采集 logcat。报告写入 `app/build/reports/device-acceptance/`，共享前检查设备序列号和应用信息。
- PdfResourceAcceptanceTest：100 次真实小 PDF 原生引擎重复渲染，检查逐帧非空/可见范围分配和文件句柄不随次数增长，输出原始观察数据。调用方主动回收测试位图；不证明 Compose/UI 位图生命周期、全场性能或物理设备达标。
- ExternalPdfAcceptanceTest：全套默认四页公共测试夹具；外部私有 PDF 仅在明确参数的专项运行中临时读取，不进入 APK。39 页用户扫描谱的引擎证据见 PHASE9_REVIEW，不替代真实谱的完整 UI、权限分发或长期验收。
- 当前四页小 PDF 测试和已有普通/大窗口截图属于模拟器软件证据，不能替代扫描大谱和真实大 Pad。
- 手动验收矩阵见 PHASE9_DEVICE_CHECKLIST，事实/修复/缺口见 PHASE9_REVIEW。每项记录通过/失败/未测及证据，不留空默认通过。

发现缺陷仍按修复→重测→再审查。真机、复杂 PDF 或长期测试未完成时 Phase 9 不通过、不进入 Phase 10。
