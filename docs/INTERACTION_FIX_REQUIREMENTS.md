# 0.9.6 交互改进要求

2026-10-10，用户实测 0.8.0 提出八项问题，并授权全部修改。本批为现有 Android 的交互修复，不新增 Phase 编号，不启动 NAS，也不推翻 Phase 9.5 备份规则。

| 用户反馈 | 本批目标 |
| --- | --- |
| 放大/全屏不可用 | 增加双指 1–4 倍缩放、放大/复位按钮，重新原生渲染可见窗口；普通全屏独立于正式演出，隐藏应用顶部/底部、工具、页码和系统栏，点按或系统返回先退出全屏 |
| 套索不明用途 | 圈选个人/可编辑草稿后直接进入移动，显示选中数量和移动/删除；不选 PDF 原件 |
| 符号只有 f | 符号选择入口常显且不藏在横滚尾部；分类选择力度、渐变、变音及演奏记号，插入预设而非识别手写 |
| 无左右滑动 | 阅读/全屏左滑下一页、右滑上一页；方向和距离门槛，页段/节目顺序继续走既有 action 与 Domain；放大后拖动平移，不翻页，编辑手势不翻页 |
| 锁定无法解锁 | 新增随时可解除的防误触编辑锁定，与不可变演出快照分开；明确冻结影响，不删除或改写旧快照，解除锁定不授予共享层权限 |
| 希望按声部授权 | “我的”提供成员与声部授权入口，全局声部授权覆盖具有该标准声部的全部曲目；单曲例外与实际分配保留，不重写权限模型 |
| 导入/录入只在管理 | 曲库原地导入、节目单原地新建、节目单详情原地编辑，复用受保护的既有服务/表单 |
| 管理并入我的 | 底部仅曲库/节目单/我的；管理中心和授权入口在管理员的“我的”，普通成员不显示，空库仍能创建管理员 |

## 安全与验收

- 既有谱、批注、历史版本、授权和冻结数据不丢失；schema 3 不变，无破坏性迁移。
- 缩放与批注使用同一 PDF 页面变换，窗口/配置变化和成员/版本切换不串状态。只分配可见窗口位图，不创建放大整页的大图；性能承诺仍需实机验证。
- 全屏不是正式演出准备，不要求节目单冻结；正式演出保留整场检查、冻结共享层和只读边界。全屏尊重用户原有图层可见性，不显示原本隐藏的草稿/个人层。
- 编辑锁定与解锁可逆，不改变演出 snapshot。修改被冻结共享版本仍需编辑草稿/安排新场次，不能因用户希望解锁就覆盖历史。
- 工具状态切换、选中操作不改变工具区高度，避免谱面位置/擦除命中跳变。
- 覆盖缩放坐标/范围/恢复、左右手势、全屏导航与恢复、锁定/解锁、符号往返、套索移动、原地创建与实际授权、非管理员入口隔离；完整回归并检查普通/大窗口截图。
- 仅向明确选择的隔离模拟器运行设备套件，不清物理 Pad 数据；物理 MatePad 手势/笔/脚踏、OEM 差异仍待用户实测。
- 新符号沿用 InkCodec 容器和归一化锚点。旧 0.9.5 不支持新增符号集合，可能拒绝含这些符号的备份；保留原文件并使用 0.9.6 或后续兼容版恢复，不静默删符号。

本批不等于关闭原 24 项 UX 待办；失败笔画恢复、表单作品保护、局部擦除、笔/手指区分及长期实机等仍分别验收。
