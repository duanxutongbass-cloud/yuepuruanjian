## 两端接口

Windows 整理器导出独立 PDF，并在设置中导出 `score-organizer-naming` version 1 JSON 字典。Android 选 PDF 后优先尝试新格式，再尝试旧格式，自动建议曲名、乐器、分类和序号；字段可手工确认修改。自定义字典加载后持久保存到设备设置，仅影响后续解析，不改已有记录。字典 JSON 需独立保留，Android 资产备份保存曲目分类和编号，但不包含设备设置。

未知编号或无编号只提示人工补录，不猜测身份、分类或授权；不实施 OCR。不自动去除乐器后缀或版本标记；桌面仍按原校对流程确认统一名称。根据文件名确定声部不等于获得授权，授权成员仍需显式选择，原权限与分配规则继续执行。

已存在序号要求明确勾选“按此编号补入已有曲目的声部”，曲名、分类须一致；重复声部、归档曲目或冻结演出拒绝，禁止静默合并/覆盖。已有成员的实际演奏分配不被补谱自动替换。

整理器当前限制全局号 001–999，Android 本批严格读取该协议，不改变 Windows 的现有编号与文件名。主产品未来 1000+ 的扩位规划保留，但不能把当前整理器称为已支持该规划；无分隔的编号和数字开头曲名存在扩位歧义，后续需要单独冻结新协议。
