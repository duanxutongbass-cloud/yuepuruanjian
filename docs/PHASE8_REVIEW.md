# Phase 8 审查

结论：2026-10-09，在本地管理端软件范围内通过。基于既有 Phase 1–7 工程继续开发；不代表生产鉴权、物理 Pad、无线脚踏或规模性能通过。Phase 9 尚未启动，sources/ 未修改。

## 实现范围

- 管理标签：快速导入、曲目、成员、标准声部、节目单、PDF 版本。新增/编辑/归档/恢复保留记录身份；曲目详情编辑乐章、声部和谱段。
- LibraryManagement 的目录读取与所有写入重新验证启用管理员；保护最后一位管理员。管理员元数据能力不授予谱权限或他人个人批注读取能力。实际声部候选、当前谱和错误来自既有 Domain。
- 默认、全局/单曲权限与分配独立。撤权保留覆盖标记，拒绝无授权的原分配而不静默换谱；修改分配校验授权/完整绑定，错误事务回滚。
- 绑定校验本曲乐章、当前有效版本、一基闭区间、整曲/乐章互斥和重复。逐步编辑可以暂时未完成，但 Domain 明确缺谱，不兜底错误谱。
- 节目项启用/归档与稳定重排；使用事务内不冲突临时槽位解决唯一索引和已归档占位，保留禁用/归档行与 ID。锁定节目不允许变更项目、顺序或引用结构。
- Shared ManagedPdfImporter 复用 SAF→私有文件→SHA-256→全部 PDF 页验证管线。失败清理本次文件；替换创建新不可变版本，activeVersionId 唯一；回滚检查真实文件、归属和全部启用页段。旧文件和批注保留，换版确认不自动迁移批注。
- ManagementViewModel 清除旧成员私有目录，取消未提交请求；表单 token 和提交快照拒绝过期覆盖，包括长时文件选择/检查。已进入不可取消原子提交的导入可能完成，切换成员不撤销已提交记录，旧结果不发布到新成员界面。
- 管理工具在可用宽度 840 dp 起列表/详情分栏，较窄窗口单栏详情保留返回列表；表单可滚动、保存状态恢复后仍验证原 token。实际 App MainActivity/Hilt 已接入管理 ViewModel，普通主导航保持原实现。

## 审查与修复

1. 修复异步成员切换取消边界：排队协程在执行前被取消也会清除 busy，避免管理操作永久不可用；已增加立即取消和检查中取消两个回归测试。
2. 编辑与 SAF 保存不可使用新目录的 token 覆盖旧表单；捕获原成员/快照，后台事务再次验证管理员及锁定状态。并发修改后表单禁用保存，设备端已验证。
3. 撤权不删除原实际分配，独立全局/单曲授权撤销不误撤另一来源；错误分配不能破坏旧覆盖。锁定快照不是永久授权，旧节目阅读 route 在显式改分配后失效。
4. PDF 替换校验全部启用绑定，拒绝短页数、损坏、新旧归属混用和过期提交；真实设备文件验证证明换版读新文件、回滚恢复旧批注，管理员未自动获谱。
5. 修正测试夹具：PdfDocument 显式 finally 关闭，外键目标先创建再创建成员默认引用；重新运行完整套件通过，未放松生产约束。
6. 统一 PRODUCT_DESIGN / ARCHITECTURE 的管理元数据与阅读权限边界，移除“完整管理尚未实现”旧状态；NAS/商业方向保持后续，不另建旧方案。
