# Phase 9.5：本地资产导出与恢复

2026-10-10 用户授权开始本阶段，并明确采用以下导出规则。继续既有 Android 工程，不重建已完成功能；Phase 9 真机/长期未验项保留，不因此标为通过。本阶段不开发 Windows、NAS、登录、多租户或自动同步。

## 权限与资产

- 活跃管理员通过显式确认导出母库全部原 PDF/历史版本、曲目、乐章、声部/绑定、成员/授权/分配、节目单和共享批注草稿/发布/冻结快照。这是独立母库备份能力，不自动授予普通阅读权限。
- 母库不含任何个人批注；管理员自己的个人层也通过个人备份另行导出。其他成员的个人层由本人分别导出，不借管理员角色读取或合并。
- 活跃成员只导出本人已保存个人批注及最小原版本身份引用，包含历史版本的本人数据；本批暂不开放成员原 PDF 导出，不附其他成员、声部、节目单或共享草稿数据，不靠复制整个 Room 文件做过滤。
- 本地成员选择仍是测试身份，不是生产认证；选择入口的拥有者可切换成员。不得宣传账号安全已完成。ZIP 未加密，持有备份文件的人可用外部工具读取，须明确保管风险；校验不证明作者身份。
- 分类/编号尚未实现，不伪造这些字段。后续新增数据须演进开放格式并保留旧档恢复测试。缓存队列、设备/登录/HID 配置、会话页码和撤销栈不是本批资产，不恢复为虚假可离线状态。

## 导出与恢复

- 系统文件选择器创建 ZIP；先在应用私有临时目录生成完整包并验证，再写目标 URI，重读整包 SHA-256 一致才报告成功。缺任一原始版本文件或校验失败，不生成声称完整的备份。
- 恢复先复制所选包到私有暂存区，检查格式/字段/ZIP 条目、大小、CRC、PDF SHA-256、实际页数、外键、唯一性、版本归属、页段、共享发布和快照一致性，再提供确认。
- 确认后重新读取备份并核对预览时的 SHA-256，拒绝中途换包。母库只恢复到所有资产表及缓存表都为空的数据库；不存在覆盖/清空旧库按钮，不自动合并或改写 ID。
- 个人恢复必须是原成员 ID，原版本 ID/hash/pageCount 一致；不按同名成员映射、不授予新谱权限。重复的完全相同记录可幂等导入；任一冲突拒绝整次事务，不覆盖旧笔画/generation。
- 保留原 UUID/String 身份、activeVersion 唯一指针、版本历史、归档状态、排序和批注 PDF 源页归一化坐标。原路径改为新的 managed storage 文件，外部 originalUri 只保留溯源。
- 校验期取消/失败不写目标资产；提交区不可取消并原子完成，文件先落盘再提交数据库，失败回滚并只清理本次文件。取消请求不能宣传为撤销已提交恢复。导出中断可能留下外部不完整文件，不把它标为有效备份。
- 进程重启后不误报成功、不锁死待选择状态；配置变化保留合理操作状态，切换成员取消旧任务并拒绝旧选择结果。进程强杀/断电可能留下未引用暂存文件，后续清扫与完整故障演练不得虚报完成。

## 必须验证

1. 母库/本人包过滤正确，管理员备份不改变 Domain 阅读授权，普通成员不能导出母库。
2. 原 PDF/历史版本、绑定/乐章、归档记录、节目单排序、本人批注、共享发布及冻结快照可恢复并实际阅读。
3. 损坏 PDF/清单 CRC、未知版本/字段、缺文件、路径穿越、重复条目、错误 owner/源页/版本及共享保留标识碰撞明确拒绝。
4. 非空库/重复母库不覆盖；个人冲突和预览后换包不覆盖；准备期取消不留下资产记录或引用缺文件。
5. 实际隔离模拟器卸载/重装后恢复，以及第二台独立虚拟设备的换机恢复；不能用内存库复制冒充重装或物理换机。
6. 真实 content URI 读写/预览/恢复、主要 ViewModel/界面状态、普通/大窗口入口、全量 Gradle 测试、APK/Lint。物理 Pad、OEM 文档提供器及云盘行为留给后续真机检查。

发现问题仍按修复→重测→再审查。具体软件通过范围、计数、工具提示及限制只在 PHASE9_5_REVIEW 记录；未来阶段以 PRODUCT_ROADMAP 为准。
