# 0.9.7 PDF 导入入口修复

2026-10-14，用户在本地 0.9.6 测试包反馈“选择 PDF”按钮为灰色，无法选谱，其余功能被阻断。

## 原因与修复

原按钮同时承担文件选择与正式导入，在曲目名称、声部或页段不合法时禁用，没有解释必填前置条件。改为两个步骤：

1. 管理员可在空表单直接选择 PDF。选中后显示文件名，以文件名去除 PDF 扩展名建议曲目名称；取消保留既有文件和输入。
2. 填写或确认声部、授权成员和页段，点击“确认导入”。未满足条件时明确显示所缺信息。原 Domain 管理员验证、权限/分配与 PDF 复制校验事务保持不变。

重新选文件会更新自动建议的名称，手动改过的名称保持原样。文件选择和返回绑定当前管理员，换身份清除所选文件；普通成员看不到入口。文件选择器不存在时显示明确错误。

版本 0.9.7 / code 9，schema 3 不变，未迁移或清理用户数据。

## 命名规则与未完成项

用户进一步要求按其独立乐谱整理器规则识别曲目、乐器、分类。当前 local-manager 明确未包含完整文件名编码/映射。用户表示将上传整理器代码和规则到仓库。

用户提供的分享链接 `https://chatgpt.com/s/cx_6acf73f746c8819184c6f94cb318ecaf` 通过网页读取失败、内置浏览器超时，Chrome 通道亦未连接成功，未读取到正文。因此本批仅做原文件名建议名称，未声称识别谱面/OCR、自动乐器/分类或按编号合并曲目。后续拿到规则后接入，未知代码不得猜测授权声部。
