- 用户确认符号面板过大，0.10.3 没有印章闪屏。面板改为阅读器现有窗口内的紧凑右上浮层，宽至多 420dp、高约 240dp、分组选择；打开/收起不改变 PDF 视口，不使用额外 Dialog。团队管理员的真实批注身份与母库管理能力投影不一致，原来会反复触发权限重载；现根据已认证团队角色判断批注权限，刷新随角色/页面身份变化，不因重载结果再次触发。反复开合、视口边界、PDF 渲染次数、管理员身份及降权后的共享编辑关闭检查均通过。源代码与行为回归可核验，未声称取得 0.10.3 源码快照逐行对比或真机通过。
- 新增独立「印章大小」50–200%，与笔宽分开，设置后再盖章；用套索选中已盖印章后点击「应用到选中印章」，支持撤销/重做。每枚印章随个人/共享批注保存大小，旧记录默认 100%，原笔画及旧印章不自动更改。NAS 严格验证可选 symbolScale，新旧批注读写相关 9 项通过。混用旧版编辑新批注不能保证保留新尺寸，请团队一起升级。
- 批量上传不再因未填资料而静默禁用预览：点击后明确指出第几份缺什么，未勾核对时有说明；读取 PDF 显示逐份阶段。同一三位曲目序号展示已入库声部，名称/分类有差异时可人工确认沿用已有元数据，不自动改号或覆盖已有分谱。真实 HTTP 已验证两个声部发布后再补六个声部，保持原编号/PDF/授权与幂等；同七位编号重复仍阻止。六文件界面完整填写后预览及提交、缺资料时明确定位均通过；真机文件选择器仍由用户实测。

## 临时测试操作记录

用户明确要求并授权操作记录近实时回传自己的 NAS，以定位真机问题，正式版前移除。固定枚举记录启动/后台、打开/选择/收起印章、尺寸调整、PDF 渲染、文件选择/读取/预检/上传发布/取消的阶段、版本、耗时、数量和视口尺寸。接口不接收自由文本，不记录密码、令牌、文件名、PDF 内容或笔迹坐标；异常只转成固定错误类型。账号/设备归属从已认证会话推导，不接受客户端冒充归属。

App 通过有界内存通道异步排队，避免主线程做磁盘和网络操作；每账号/设备 AES-GCM 加密持久队列最多 500 条，每批 20 条，网络正常时约 2 秒内开始回传，失败退避和离线补传，只有一致回执才删除，回执丢失按固定事件 ID 重发。NAS 验证现有设备/账号权限并幂等落盘，仅管理员可查询，管理员读取有审计。写入/查询时清理超过 30 天的记录，每账号最多 2000 条、实例最多 50000 条；没有另装后台清理任务。

「团队账号与设备」显示临时诊断状态和说明。正式 release 构建 `TEST_OPERATION_LOGS=false`，NAS 可设置 `TEST_OPERATIONS_ENABLED=0` 禁用。商用前移除入口与采集，并清理测试记录；备份中可能保留既有测试记录，应遵守同样清理期限。

接口（仅测试）：认证 POST `/v1/test-operations`；管理员认证 POST `/v1/admin/test-operations/query`，body `{after:0,limit:200,accountId?:UUID}`，按 sequence 向前分页。时间同时保留客户端 at（毫秒）和服务器 receivedAt（秒），排查以服务器收到时间为准。
