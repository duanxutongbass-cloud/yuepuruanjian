## 当前边界

- 本地成员选择不是生产身份认证；拥有设备入口的人可以选择管理员，不能宣传为安全联网商业版。
- 快速导入每次创建新曲目和一个整曲绑定；已有数据的多声部/乐章/版本/授权/节目单编辑使用其他管理标签，不把快速导入当替换。
- 普通用户未授权声部不显示；管理员也不自动获得所有谱的读取权限。
- 阅读恢复是 SavedStateHandle 会话/实例恢复，不是永久阅读历史。
- 系统已配对 HID 输入的软件入口已实现；真实蓝牙无线/脚踏硬件未验收，专用 BLE/GATT 协议未实现。API 26–28 零 vendor/product 身份设备不保证识别。
- 本批次本地正式演出模式已实现；联网/NAS、多租户及运营尚未实现。没有下载器或全场位图预加载，准备上限 10,000 页，不代表该规模性能已验收。
- 物理 Pad、真实复杂谱完整 UI/长时间运行仍未完成验收。39 页扫描谱原生引擎及 3 分钟小谱 UI 检查已补，不代表真实排练通过。导入被进程强杀时可能产生未引用文件，孤儿清扫待完善。
- 全表事务快照、管理成员×曲目 Domain 投影和逐节目单锁定查询需要在规模化前评估查询优化。
