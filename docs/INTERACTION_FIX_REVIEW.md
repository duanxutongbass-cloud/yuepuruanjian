# 0.9.6 交互修复审查

日期：2026-10-10。依据用户实测 0.8.0 的八项反馈及随后授权，基于现有 0.9.5 增量修改。结论：本批软件范围通过；并非完整 Phase 9 真机/长期演出验收，也未启动 Phase 10。

## 八项结果

1. 全屏与正式演出分开。全屏隐藏应用顶部栏、普通导航、页码和工具，保留当前可见谱/批注；点按或系统返回先退出全屏。保持常亮，读谱/批注/演出错误触发退出全屏显示错误。正式演出改用播放/停止图标，保留原准备与冻结校验。
2. 双指缩放、放大和复位，限制 1–4 倍。按手势中心与拖动计算平移，PdfRenderer 重新渲染可见窗口，不放大旧位图；PDF 与批注共用变换，缩放/平移/全屏状态使用 SavedStateHandle，按成员、版本及阅读上下文隔离。
3. 阅读/全屏左滑下一页、右滑上一页；距离与水平意图门槛防误触，放大后单指拖动平移、不翻页。编辑手势不翻页，批注未就绪或保存期间不交叉操作；复用既有 action、授权页段与节目游标。
4. 套索圈选后直接进入移动，显示选中数量和移动/删除操作。只选批注，不改 PDF 原件；对象橡皮与撤销语义不变。
5. 符号入口常显，分类面板提供 26 个常用预设：力度、渐变、变音和演奏。渐强/渐弱、延长、重音、断奏、保持用图形绘制，其余保留文本；不是手写识别，不宣称全部音乐符号。
6. 新编辑锁定随时可解除，按成员保留会话状态；不删除笔画，不授予共享层权限，不解冻历史快照。“冻结本场共享版本”是独立的显式确认操作，说明结构保护及继续草稿/新场次边界。
7. 曲库就地导入、节目单就地新建、详情就地编辑；复用既有受保护服务与可滚动表单，业务页只显示相关工作区，不夹入创建成员等无关表单。管理中心保留完整标签。
8. 底部仅曲库、节目单、我的。管理中心及成员与声部授权在管理员“我的”；全局声部勾选覆盖全部相应曲目，单曲例外和实际分配独立。空库能创建管理员，普通成员不显示管理操作。历史 admin 路由保留以兼容旧返回栈，但不是底部标签。

## 审查发现与修复

- 首轮发现条件工具区高度改变，套索选择/擦除时谱面变换跳动。改为固定高度的常显符号/选择行，移动、擦除和撤销设备回归通过。
- 写画测试曾从 Fit Page 白边起笔，未命中 PDF；改用实际 PDF 归一化坐标注入手势，保留不越页断言，没有放宽成“不崩溃就通过”。
- 全屏改由阅读 ViewModel 统一保存，避免导航恢复重置局部状态；错误退出全屏、批注就绪门禁和新建表单切标签后重复触发均已处理。
- 旧导航/冻结按钮用例随新语义更新；符号 JSON 测试使用真实 Android JSON 测试环境。修复 Lint 手势缩进/结构问题，未抑制检查。
- 首轮 Phase95Recovery 模拟器出现系统界面 ANR，系统对话框遮住窗口焦点，两个脚踏用例失败。该轮不算通过；关闭后改用既有隔离 Phase4Pdf 并保持环境唤醒，完整重跑通过，没有绕过焦点断言。

## 保留边界

- 没有操作物理 MatePad。真实触控延迟、笔/掌触、蓝牙无线、OEM 系统栏及长期演出仍待实测，不把软件通过当实机通过。
- 双指缩放在阅读/全屏进行，写画/套索不同时缩放翻页；尚无笔与手指自动分工。缩放上限与可见窗口内存保护不是容量性能承诺。
- 历史演出快照仍不能覆盖/解冻，新编辑锁不是快照解锁开关；后续共享改动编辑草稿并安排新场次。
- 套索按轨迹点/符号锚点选择，橡皮删除整对象；没有局部擦除或任意符号大小编辑。
- 新符号沿用 InkCodec/归一化锚点。旧 0.9.5 可能拒绝含新增符号的备份，须用 0.9.6 或兼容后续版恢复，不静默删符号；未加密 ZIP 边界不变。
- 失败笔画恢复、表单作品保护等 UX 工作包未全部解决。本批不关闭全部 24 项待办，不宣称正式演出可靠性最终通过。
