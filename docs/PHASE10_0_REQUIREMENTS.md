# Phase 10.0：联网规则与工具盘点

更新：2026-10-10。用户已授权继续 Phase 10。当前先进行 10.0，不重新开发 Android，不将本文件当成服务器已实现。

## 用户本次明确确认

- 没有现成 Windows 整理工具可复用；10.1 新建工具。历史聊天的“GitHub 半成品”不能当成真实仓库证据，没有可审查项目就不等待虚构旧代码。
- 成员姓名、人数、声部名称、声部分配和授权由管理员自由添加/编辑，不能内置七人名单或固定乐器。七人是首批试运行场景，不是数据模型或产品人数上限。
- 分类字典同样由用户维护；没有已交付编号/字典文件，不凭文件名或测试数据猜测正式字典。
- 全局曲目流水号采用至少三位显示：001–999 后继续 1000、1001…；不回绕、不按分类或乐器重置。第二组两位自定义分类编号不受此次扩位影响。
- 外网同步是必需能力，不能只交付局域网版。NAS 的 DSM、实际内存、套件、网络入口和独立备份设备目前未知。
- 保留此前确认：离线使用已授权内容、发布后自动分发、文件级隔离、原 PDF 与个人批注分离、开放取回；管理员母库及共享层与成员本人个人层分开备份，成员暂不导出 PDF。

## 已有代码复用边界

当前 Android 0.9.6 / schema 3：成员、标准声部、全局授权、单曲例外、实际演奏分配均为 Room 动态记录；DatabaseModule 没有生产种子名单。继续复用 ScoreResolver、RoomScoreRepository 和批注源版本/源页归一化坐标。

没有联网客户端、生产身份认证或 NAS 服务。Manifest 只有网络状态权限，不代表能下载。全表 LibrarySnapshot 是本地事务输入，不能直接作为普通成员网络响应；当前母库 ZIP 也不能整包恢复到普通成员设备。

现有版本的 hash/pageCount/pageIndex 指向原始 PDF。授权分谱改变文件 hash、页数和文件页序，必须另设配送文件身份及原版本/源页映射，不能把分谱文件冒充原版本或给 reader 一个错误 hash。具体边界见 TEAM_SYNC_CONTRACT。

## 开发流程基线

管理员创建成员/声部/分类 → 导入 PDF 到受管理存储 → 全局编号、声部/乐章/页段绑定 → 检查文件及授权文件边界 → 预览每名成员实际可见清单 → 显式发布 → 服务产生成员专属变更 → 已注册设备自动拉取、校验、原子提交 → 明确可离线 → 断网演出 → 母库与本人批注分别备份/恢复。

上传成功不等于发布成功，发布成功不等于设备同步成功；节目单只决定顺序，不触发首次分发。授权基于服务端真实身份及当前权限，不信任请求里的 memberId/role，也不因管理员角色默认授予阅读权限。

## 实施默认与待冻结细则

以下为后续实现的审查草案，不冒称用户已逐项确认或完成代码验证：

| 项目 | 保守实施草案 / 进入条件 |
| --- | --- |
| 编号（用户已确认） | 全局流水号至少三位显示，001–999 后继续 1000、1001…，不设 999 截断、不回绕、不按乐器或分类重置；两位自定义分类号保持独立。UUID 为永久身份，归档不重用编号；解析不能截取固定三位，排序按流水号数值 |
| 临时替补 | 支持显式单曲/声部授予，可选 UTC 有效期；不给固定替补角色。在线到期停止分发；断网已有文件不可即时撤回的边界必须说明 |
| 撤权 | 服务端立即停止新的授权下载/同步；客户端收到新权限清单后按引用校验清理撤权文件，不删除本人批注；不能把冻结节目单当永久授权 |
| 多设备批注 | 使用服务端修订号及请求幂等标识；旧基线写入冲突保留双方，人工处理，不按设备时间静默覆盖。完整协同/自动合并不纳入首批 |
| 演出中更新 | 新文件先下载到暂存并校验，不在正在阅读/演出中静默换版；更新授权要失效/重验，不回退到错误声部 |
| 私人批注 | 应用管理员没有读取其他成员私人层的 API 权限。运维/root 与应用角色不同，不能宣称运维绝对无法访问；涉及私人灾备同意及加密/恢复密钥须明确后再开放 |
| 外网 | API 支持受保护的外网 HTTPS 入口；证书、认证、设备鉴权必须有验证。VPN 或受控网关的实际部署方式待 NAS/路由条件核验；不映射 DSM、SMB 或数据库到公网 |
| 技术栈 | Windows 工具及服务端框架选型在 10.1/10.2 实施前落定，核对本机 SDK 与依赖许可证；不能因发现 dotnet/node 命令就认定可构建或已交付 |

NAS 未知参数是实机部署门禁，不要求用户提供密码/管理员令牌。可提供去除敏感信息的 DSM 系统信息截图：型号、DSM、内存、存储可用量、套件情况；再核对外网入口和独立备份位置。不得替用户升级 DSM、买设备、开放端口或推送曲谱。

- NAS/外网/备份条件核验，或明确标为后续部署阻塞，而非实机通过。
- 已确定规则同步唯一规划和状态；10.0 不因文档写完就宣称整阶段通过，Windows、NAS、同步和七人试运行分别验收。
