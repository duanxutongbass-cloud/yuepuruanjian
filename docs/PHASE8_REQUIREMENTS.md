# Phase 8：管理端完整化

状态：2026-10-09 本地管理软件范围通过，实际证据见 PHASE8_REVIEW。继承 DEVELOPMENT_RULES，基于当前工程，不做生产登录/NAS/商业版。

- 管理员专用的成员、标准声部、曲目、乐章、曲目声部、PDF/版本、谱段、节目单与节目项的创建、编辑和归档/恢复。
- 管理元数据是显式管理员权限；非管理员不得读取此目录。管理员元数据权限不授予读谱或他人个人批注权限，阅读/演出仍走原有 Domain。
- 全局/单曲授权与实际分配分开，默认声部不自动授权；每成员每曲最多一条启用覆盖分配。撤权不静默改奏默认或其他声部，Domain 明确报错。
- 绑定支持整曲或本曲乐章，不混用、不重复；一基闭区间校验当前版本页数。逐步编辑未完成的谱段可以暂时不可读，但不得错误回退到其他谱。
- PDF 替换走同一 SAF→managed storage→SHA-256/PdfRenderer 管线；版本不可变、activeVersionId 唯一。切换/回滚验证归属、实际文件和全部启用绑定页段；旧文件和批注保留，不自动迁移，UI 明确确认。
- 锁定节目单的节目项、引用曲目/乐章/声部/绑定/PDF 版本禁止改写；历史快照不覆盖解锁。成员授权/分配的显式修改仍必须使现有阅读按 Domain 失效或重验，不扩大权限。
- 节目单追加、启用/禁用、归档/恢复、稳定排序；重排在一个事务中处理唯一 sortOrder，包括已归档占位，不丢数据。
- 后端所有读写重验管理员、外键目标、唯一和归档约束，保护最后一个启用管理员。编辑基于已读快照，旧表单/长时 SAF 返回不能无提示覆盖新数据。
- 普通/大 Pad 工具化管理界面，真实 ViewModel/Room 结果，Loading/Empty/Error 与操作进度，成员变化立即清除私有管理目录和过期文件请求。

实际完整构建、JVM/Room/Android 测试、Lint 和管理界面截图复核后才能填通过；数据库如改变必须迁移保留，否则保留版本 3。
