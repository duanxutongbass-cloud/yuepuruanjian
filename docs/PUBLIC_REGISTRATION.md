## 已实现

1. “注册账号”使用独立 `/v1/auth/signup`，不需要邀请码，不接受角色、账号/成员/团队身份覆盖；个人批注上传同意可选。原 `/v1/auth/register` 邀请契约、密码、设备撤销、停用、七天核验保留。
2. 未加入、待审核、被拒绝三种状态只可访问本人身份/设备/密码/退出/同意和申请入口。HTTP读团队正文前及各模块事务内重验，旧APK忽略新增字段也不能绕过。App状态加密恢复；Scope/Sync拒绝并清掉旧集合，Gate遮挡旧本机/团队内容；批准后先核验身份再同步，未分配时显示等待分配。
3. 管理员在“团队账号与设备”生成或更换乐团码，关闭后不再显示明码，NAS只存摘要；更换需确认和当前代次，旧码失效但不撤销已有申请。未加入/拒绝可输入新码申请，管理员查看最早200个有效申请及总数，按姓名/账号确认批准或拒绝；处理后刷新继续查看其余。
4. 申请和审核使用独立requestId、基代次、SQLite写事务和持久回执，丢回执重试不重复执行；拒绝后重新申请有新代次，旧审核不能覆盖。码、密码、令牌不写审计/诊断，App状态字符串脱敏。批准只成为普通成员，不授全库/管理员权限；待审不能成为发布或节目单接收人。
5. 旧账号默认joined；不重建现有乐团或用户数据。后端SQLite核心版本2，迁移重读锁内版本支持并发启动，旧服务拒绝新库，禁止直接切旧镜像打开2版库。App Room仍6，原编号、PDF、批注、冻结与个人文件夹保留；已进入冻结演出的有限继续例外保留，退出即结束，不由注册门禁带回首页。
6. 旧服务器未实现signup时明确提示“NAS尚未开放”，保留原登录/邀请；测试期版本说明和公开更新提示可在账号门禁页看到。本项仅现有单实例，不提供多乐团、组织目录、订阅或收费，编号19/Phase11边界未跨越。
