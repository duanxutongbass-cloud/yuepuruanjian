# 0.10.4：管理员、批量上传与整曲节目单

2026-10-16。APK 0.10.4（16），数据库仍为 schema 6。同签名覆盖安装，保留账号独立数据。本机验证、NAS 升级及更新渠道发布均已完成，公网完整下载校验通过。

## 用户反馈及范围

- 团队管理员此前只有账号/批注管理，MainActivity 对团队模式关闭本机母库管理，缺少真正的 NAS 上传与节目单接口。不能将团队账号改为本机 ADMIN 或打开本机写入界面冒充已同步；逐谱授权仍由服务器验证。
- 新版曲库提供「上传乐谱到乐团」及「管理乐团曲库／删除与恢复」，节目单提供「管理节目单／整曲选曲」。管理员可为自己接收已有曲目的全部分谱；普通成员没有上传/管理入口。
- 一次多选最多 50 份 PDF，每份不超过 100 MB/2000 页；先复制到账号私有暂存目录、校验 PDF，再按同源整理器字典识别。每份可独立修改曲名、七位编号、声部、分类及接收成员；预览后整批原子发布，不改变源 PDF。09 组合文件禁止按独立声部发布。
- 发布请求在 noBackupFilesDir 按账号保存固定幂等 ID，中断/进程重开后重试；完成的上传不重复传输。取消未发布批次须经服务器事务确认，取消后延迟上传也不能继续发布；已经发布的批次只核验回执，不当成未发布取消。
- 曲库、节目单删除使用回收站：保留原 PDF、编号、笔迹和授权，恢复时不重用编号。团队曲目删除会下架选中的全部声部分谱，成员同步后撤销入口。服务器用目录版本检查并审计，旧成功请求重试不会再次删除已恢复的乐谱。
- 本机曲目删除同时归档相关节目项，锁定演出引用禁止删除；恢复曲目不自动复活已移除节目项，界面明确提示需重新添加。节目单本身可删除及恢复。
- NAS 节目单按唯一曲目序号选择一首乐曲，明确列出全部声部；同名不同号保持独立。同一曲目后来补入的声部依编号继续归集。服务器按节目单可见成员和原有 PDF 授权过滤个人演出曲目，不因选中节目单额外授予文件权限。
- 「我的阅读声部」只选择本设备的默认阅读声部，不增加授权。单个获授权声部仍自动匹配；多声部账号可先选默认声部，再打开演出谱。
- 启动/返回前台检查新版本（15 分钟节流）；非阅读页面显示醒目的新版提示和更新入口，全屏谱面不显示横条。临时「版本更新内容」按钮从本地 assets 离线读取，BuildConfig.TEST_RELEASE_NOTES 标记为商业版移除项。0.10.3 本次仍通过「我的→检查新版本」升级后才能使用自动提醒。
