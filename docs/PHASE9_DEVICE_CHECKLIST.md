## 性能采样方式

连接并授权 USB 调试后，在项目根目录使用只读采样工具；serial 取已识别的实际设备，不自动选择多个设备中的某一个。

```powershell
./tools/Collect-PadDiagnostics.ps1 -Serial <actual-device-serial> -Label normal-pad-baseline
./tools/Collect-PadDiagnostics.ps1 -Serial <actual-device-serial> -Label normal-pad-reading -Samples 12 -IntervalSeconds 5
```

先保持应用前台并执行对应场景，再采样；后台/未启动包的 meminfo 不能当阅读内存。gfxinfo 是累计观察且可能有旧帧，须对齐采样时间和场景，不能把它直接当全部 PDF 翻页耗时。没有进程则记录未采到，不给零内存的假结论。

原始数据默认位于本项目 build 目录；不自动上传。截图/日志/曲谱另行确认，避免采集其他应用或私人内容。填写失败须附复现步骤、版本、修复和重测结果；最终通过依 PHASE9_REQUIREMENTS 和 DEVELOPMENT_RULES。
