# Phase 5：完整批注系统

状态：2026-10-09 在本批次范围内通过。实际实现语义、验证和后续实机限制以 PHASE5_REVIEW 为准。以当前原生 PDF 与 Domain 为基础。

## 功能

- 手写笔：轨迹、颜色、粗细，实时反馈。
- 荧光：可区分的透明标记，不遮住乐谱。
- 橡皮：清晰删除语义，可撤销。
- 套索：选择和操作批注；至少移动、删除并可撤销。
- 撤销/重做：针对编辑动作；不能撤销成其他成员、页或版本的内容。
- 音乐符号：可选择、定位、移动和删除，不只是工具图标占位。
- 我的批注 / 共享批注双层：独立显示隐藏，个人数据按成员隔离。
- 持久化：重进页面、配置变化和重启后不丢已保存批注，失败不能显示虚假“保存成功”。
- PDF 页面坐标映射：按具体版本、源页索引保存归一化坐标，Fit Width/Page、滚动、旋转和窗口改变后对齐。
- 共享流程：草稿 → 发布/锁定版本 → 演出稳定快照。

## 权限与共享语义

- 批注读写前验证当前成员对相应曲目声部/页段的 Domain 权限。未授权不能通过传入任意版本/页 ID 读写。
- 个人批注只属于本人；不得读取其他人的私人层。共享层不能替代谱授权。
- 共享编辑与发布必须有管理权限，并继续满足谱访问权限；不以客户端按钮隐藏替代仓储写入校验。
- 草稿不自动暴露给普通成员；发布内容不可原地覆盖。后续草稿修改不影响旧发布版本。
- 演出稳定快照必须捕获已发布状态（包括没有共享批注的页），不能在逐页打开时重新取最新草稿/发布内容。
- 锁定快照不能被橡皮、撤销、重做、发布或切换窗口改变；版本变化不能让旧版批注静默映射到新版 PDF。
- 具体数据库/工具交互方案属于 Phase 5 实现决策，需记录于阶段审查，不伪装为主项目早已冻结的设计。

## 验收

覆盖编辑工具、图层开关、坐标往返、页段/版本/成员隔离、撤销重做、保存重载、发布后的草稿隔离、稳定快照与异常状态。Room 升级测试验证 Phase 4.5 成员、曲目、版本、授权和节目单保留。

实际执行 Gradle 构建、单元/Room 测试、Lint；真实 PDF 上的批注叠加须在 Android 集成/Compose 测试和普通/大 Pad 截图验证。配置变化、保存失败、并发/取消及内存压力不能只靠 happy path。

Phase 5 不实现蓝牙、云端协同、多租户或完整管理。真机笔延迟/掌拒及厂商差异不得用模拟器截图冒充验收，列入后续实机验证。
