# 编号 8 下载管理（0.10.8 已发布）

App 0.10.8（20）已发布，NAS 后端继续运行 0.10.7。沿用账号私有目录、现有 NAS 逐 PDF 鉴权/Range/If-Match 与最终原子入库流程，不修改原 PDF、编号或原授权规则。本批不新增 NAS 接口或 OS 后台服务。

## 使用

在曲库或“团队账号与设备”打开“下载管理”。“暂停下载”作用于整个队列；已验证缓存仍可阅读。“继续下载”会先核验当前账号和授权清单；断网时保留内容，联网后再继续。可按曲名、编号、分类、声部搜索，或点“仅未完成”。100% 接收仍可能处于校验/等待入库阶段，以“已入库”为准。暂存和暂停状态跨重开保留，列表的曲名/授权来自下次联网的新清单。

## 验收范围

- 曲库和团队账号页可打开下载列表，显示编号、曲名、声部、逐文件字节进度、等待/下载/校验/等待入库/完成/失败状态。大曲库使用可搜索的懒加载列表。
- 支持暂停整个下载队列、继续/重试未完成文件；暂停状态与私有暂存跨重开保留。已完整接收但尚未入库的文件也保留，不因后续文件中断全部重下。暂停仍继续账号/当前授权核验，收到撤权立即生效。
- 每次继续先重新核验身份和新清单；服务器每个 Range 请求重新鉴权并带精确 If-Match。验证 ETag、Content-Range、长度及最终全文件哈希/PDF 页数。忽略 Range 的合法完整响应重新写入暂存，绝不追加拼接；中断保留前缀，错误内容不入库。
- 只有完整校验且最终清单再次一致后才原子入库。暂停/失败/取消不标 CACHED、不增加权限；已有合法缓存保留。收到撤权时删除本队列对应的未完成暂存、移除队列元数据，不删除原 PDF、历史批注或别的账号文件。
- 切换账号/设备、过期、撤权、进程重开及故障恢复必须保留隔离；进度流只由下载界面订阅，不向阅读页广播高频状态而引入印章刷新。
