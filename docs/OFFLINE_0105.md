# 0.10.5 离线曲库与重连核验

2026-10-16。**已发布**：NAS 镜像 0.10.5 健康运行，App 更新入口已切换到版本 17；公网完整下载 SHA-256、大小和 ETag 一致，5 个私有接口未登录均返回 401。升级前完整备份 `/data/backups/pre-0105-20261016.zip` 内置校验通过。发布前容器内断言 `SESSION_SECONDS=604800` 和 APK 哈希通过，原数据卷及旧镜像保留。

升级后先联网登录并同步一次。App 将账号、设备、当前登录凭据的哈希和服务器授权清单加密保存到不参与系统备份的私有目录；重新打开 App 时，只恢复仍在核验期限内、大小和 SHA-256 完整匹配的本机 PDF 与对应节目单。缺失文件不标记为已缓存，不自动改编号或合并同名曲目。个人批注仍按账号在本机保存，重连核验后沿用既有冲突确认和上传机制。

服务端会话初始有效期为 7 天；有效会话每次通过 `/v1/me` 核验后续期 7 天，普通传输不续期。App 离线权限取最近完整核验清单的 7 天截止与服务器会话截止中较早的一项，离线使用不续期。首次登录、过期、凭据或设备不匹配，以及收到 401/403 身份拒绝时，不以旧凭据打开曲库。普通网络中断/5xx 可恢复已验证缓存，证书错误及重定向不进入离线回退。记录时间高水位并限制回拨，运行进程使用单调时钟防止延长期限；App 到期主动关闭团队阅读，重连先验证身份，再更新授权和同步内容。

收到授权清单后，先废止旧离线检查点，再落盘撤权和新检查点。即使后续下载中断、进程关闭或重启，也不能恢复已撤权文件的阅读权限；保留不可变 PDF 和个人批注，不把恢复权限作为下载失败的回退。完整缓存的已授权分谱仍可恢复；节目单缺整首曲目缓存时不伪装为准备完整。
