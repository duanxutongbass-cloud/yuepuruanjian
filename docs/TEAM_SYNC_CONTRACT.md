# 单乐团发布与同步接口边界草案

2026-10-10，Phase 10.0 设计输入。不是 OpenAPI 成品、可调用服务或已冻结实现；以 PHASE10_0_REQUIREMENTS 的确认/待定分类为准。联网协议版本与本地 ZIP formatVersion 分开维护。

## 身份与自定义数据

姓名、声部、分类由管理员输入；成员/标准声部/曲目/版本/节目项都用稳定 UUID，名字和编号可编辑但不改变身份。数据库不写死七人；验收可动态生成七名、更多/更少成员以及不同声部的合成样例，生产不预置这些样例。

用户已确认全局曲目流水号至少三位显示，001–999 后继续 1000、1001…，不回绕或按分类/乐器重置。两位分类号独立；接口、导入和文件名解析不得假设曲目号恰好三位，排序按流水号数值。后续测试覆盖 998、999、1000、1001 的生成、排序、导入导出和重号拒绝。

服务认证得到 principal 和 deviceId，服务端校验注册关系和实时角色；请求自报成员或管理员身份不能扩大权限。管理员管理目录与谱文件读取分别鉴权；网络成员端不能继续使用本地任意身份选择器冒充登录。首次接入需显式绑定旧成员 ID，不能按同名自动合并。

## 原件与配送资源

- SourceVersion：原 scorePdfId/versionId/hash/pageCount，不可变；activeVersionId 仍是唯一当前版本来源。
- DeliveryArtifact：独立 artifactId、字节 hash/size、配送 pageCount、sourceVersionId、按序 pageMap、生成工具/版本及发布 revision。下载只提供授权 artifact，不提供母库路径或外部 content URI。
- pageMap：每个配送 PDF 页映射到原版本的源页（原记录零基，UI 显示一基），并核验尺寸/旋转/裁切变换。简单完整页复制可以保持归一化坐标；改变裁切/旋转时必须显式转换和测试，不猜测比例。
- 原版批注仍按原 versionId/sourcePage 归一化坐标关联；页面显示、cache hash 和原版本 hash 不能混用。Android 10.3 需要显式配送模型/适配及必要迁移，不能只把 managedFilePath 换成新下载路径。
- 同一 PDF 跨声部页段，不能因 UI 隐藏其他页就发送整文件。未验证的分谱阻止发布；不采用简单截页后宣称没有隐藏资源/附件泄露的做法。独立声部文件、受审查分谱生成与原页映射必须通过内容及越权测试。
- 源文件 hash 相同不等于有权下载。逐请求校验当前成员、设备、发布版本和资源授权，续传/重试同样校验；不暴露共享文件夹、永久公开链接或绕过鉴权的静态 URL。

## 接口工作清单（路径暂定）

| 接口族 | 边界 |
| --- | --- |
| 会话/注册 | 首次认证、邀请/设备绑定、令牌续期/失效；离线阅读不依赖实时续期。临时失败不清空用户资产 |
| 管理目录 | 成员/声部/分类/全局编号、权限和分配；新增/编辑/归档，最后管理员保护，基线 revision 防过期覆盖 |
| 导入/上传 | 受控暂存、大小/hash/页数校验；幂等请求、失败重试，不自动发布。元数据不得引用尚未完整提交的文件 |
| 发布预览/提交 | 基线 revision 的成员可见清单和配送资源校验；提交原子生效，失败无半发布。批注快照仍不可覆盖 |
| 我的变更 | 根据认证身份生成投影；包含 revision/cursor、授权新增/更新、撤权 tombstone、节目单及映射，不返回全表快照或他人私人数据 |
| 授权下载 | artifact 逐文件鉴权；稳定内容标识供续传及完整性校验。旧 cursor/下载任务必须重验，不因历史 manifest 还在就绕过撤权 |
| 设备确认 | 记录“已提交本地的 revision + 校验成功资源”，不能把发出请求或收到清单算已同步；按设备区分状态 |
| 本人批注备份 | owner 由服务身份确定，scope 对应原版本/源页；CAS 修订、幂等、冲突保留，本人接口不返回他人个人层；另设已知情确认的本团队管理员读取入口，逐请求鉴权并审计 |
| 母库备份/恢复 | 管理员独立授权；复用开放资产语义及格式演进，不把数据库目录复制冒充一致备份。私人灾备另设同意与密钥边界 |

## 客户端提交顺序

获取清单与鉴权 → 校验协议与引用 → 私有暂存下载 → hash/页数/映射校验 → 原子提交 Room 元数据及可用文件引用 → 确认设备同步 → 清理已无授权且无合法引用的文件。失败保留旧的完整可用版本，不把半下载标 CACHED；权限收回不能保留旧权限作为通用失败回退。已开始冻结正式场次的有限完成例外见下文，不等于保留旧通用授权。

撤权不销毁本人批注。无法再看谱的历史私人笔画仍需有本人取回路径；旧本地 AssetArchiveStore 要求启用成员，与生产账号撤销后的备份能力需在 10.3 分开审查。NAS 账号失效不能成为永久锁死私人资产的机制。

现有原型设备可能已经有完整母库/多个成员文件。新网络投影过滤不会自动清除这些旧字节；接入生产需管理员先做独立备份、确认数据归属及设备隔离迁移，不静默清库，也不声称仅换登录界面便满足文件级隔离。

## 必须实际验证的场景

1. 自定义名字/声部、空字典、修改名字、人数变化不改变 UUID/授权，不能使用七人硬编码。
2. 混合母 PDF 经授权分谱后仅配送合法页面/内容；sourcePage、坐标和旧批注不串页，原件/配送 hash 不混用。
3. 默认声部不自动授权、单曲例外不扩大全局、实际分配不扩权；多来源撤回、替补到期和管理员身份分别测试。
4. 猜 artifact/他人 memberId、续传、旧清单、令牌/设备撤销、跨账号残留缓存不能绕过服务端下载权限。
5. 发布中断、重复提交、metadata revision 变化不半发布；设备确认失败不能误记已同步。
6. 换版/回滚、冻结节目单、演出中更新保持历史，异常明确停止/重验，不静默读另一份谱。
7. 离线编辑/重装/换机、旧基线写冲突、重复请求、撤权后本人取回不静默丢笔画或读他人层。
8. NAS 停服、数据库与文件一致恢复、开放格式取回及私人恢复权限分别验证；备份文件还在不等于恢复演练成功。

### 身份与隔离键

| 对象 | 必需身份/关联 | 不变量与失败处理 |
| --- | --- | --- |
| Account / DeviceSession | accountId、memberId 显式映射、deviceId、sessionId、authRevision | 每人独立账号密码；共享设备支持多账号切换。服务 principal 决定 owner；不能凭请求 memberId。切换使旧会话任务和回调失效；旧数据不得显示给新账号 |
| Permission / Assignment | memberId、partDefinitionId / piecePartId、grantId、permissionRevision；期限方案待决 | 默认声部、实际演奏分配不自动授权；多来源授权按 Domain 合成。名字可改、UUID 不变，归档/撤销作为独立事件 |
| SourceVersion | versionId、scorePdfId、sourceHash、sourcePageCount | 原件不可变；activeVersionId 是当前版本入口，历史版本保留；不能用配送字节冒充原件 |
| DeliveryArtifact | artifactId、sourceVersionId、artifactHash、size、pageCount、pageMap、generatorVersion | 一个配送页明确映射原版本/源页与坐标变换；分谱内容审查通过后才发布，成员不接收母库 |
| Publication | publicationId、baseRevision、revision、manifestHash、permissionRevision | 管理端显式发布；CAS 原子提交；引用资源全部验证完成，不能半发布；旧版不静默换入演出 |
| PersonalAnnotation | ownerId、sourceVersionId、sourcePageIndex、generation、operationId、payloadHash | 原坐标、个人所有权；CAS/幂等；同 key 不同 payload 拒绝，冲突保留双方，禁止按客户端时钟覆盖 |
| SharedRevision / ConcertSnapshot | revisionId、documentId、createdBy；concertId、manifestHash、revision 引用 | 草稿、已发布、演出冻结三者分离；快照不可变，不把可解除编辑锁当解冻权限 |
| DeviceReceipt | deviceId、accountId、sessionId、revision、artifact 校验集合、commitId | 只确认已原子提交的本地状态；按设备和账号展示，不把一台共享设备等同一个成员或全团 |

### 请求/响应最低契约

所有变更请求携带 requestId（重试稳定）、协议版本和适用的 baseRevision；服务端以认证身份确定权限。重复 key 与相同规范化 payload 返回原结果；同 key 不同 payload 返回明确冲突。已知提交结果与“结果不明”分开，结果不明先查 operationId 状态，不盲目创建第二份。鉴权先于幂等结果读取，撤权后不能用历史请求取回他人/未授权资源。

- 上传：init → 分块/续传 → complete(hash/size/pageCount) → VERIFIED_STAGING。缺块、哈希不符或格式不合法保持不可发布；暂存过期策略在服务实施时确定。
- 发布预览：返回 baseRevision、每名成员获准 artifact 列表、内容/映射校验结果及阻塞原因；commit 必须匹配该基线，过期拒绝并重新预览。
- 我的变更：返回 protocolVersion、revision、nextCursor、permissionRevision、授权资源及 tombstone；cursor 过期返回需完整“本人投影”重建，绝不降级为全表母库。撤权事件不能被旧发布恢复。
- 下载：按 artifactId + 内容版本支持续传，逐请求检查当前账号/设备/权限；版本变化不能拼接两份字节。下载 URL 不充当永久授权。
- 本地提交：暂存文件先校验，崩溃前后仅存在旧完整集合或新完整集合；孤立暂存可重试/回收，不提前标记可读。撤权状态不因下载失败回滚。
- 确认：receipt 幂等写入；发送失败保持本地可读，但管理员显示“确认待回传”，不伪造服务器已收到确认。再次确认不重新下载/重复提交。
- 批注提交：成功返回 operationId/generation/payloadHash；基线冲突返回已授权的当前 generation 与冲突标识，保留本地候选。本人 API 不向其他成员返回数据；用户新批准的管理员读取只经独立的同团队授权入口，且数据首次上传已有成员知情确认，记录访问审计。
- 错误分类：AUTH_REQUIRED / FORBIDDEN / DEVICE_REVOKED / BASE_CONFLICT / CURSOR_EXPIRED / INTEGRITY_FAILED / UNSUPPORTED_PROTOCOL / RETRYABLE。不得把永久撤权无限重试，或把格式不支持当空库清空。

路径及具体 HTTP 状态/序列化仍是 10.1/10.2 实施输入，不是已部署 OpenAPI。演出中撤权例外、个人 NAS 备份默认开启及管理员可读已确认；离线账号期限、密钥及恢复细节见 PHASE10_0_REQUIREMENTS 待决表。

### 状态词汇：六个不同的事实

| 状态 | 达成证据 | 仍不能推断 |
| --- | --- | --- |
| 已上传 | 服务收到完整资源并完成上传校验 | 已发布、成员已收到 |
| 已发布 | 原子 publication revision 已提交 | 任一设备已下载 |
| 已收到 | 指定账号/设备收到清单或字节（分别标注） | 文件完整、可读 |
| 已校验 | artifact 字节 hash/大小/页数/pageMap 均匹配 | Room 已提交、本地可打开 |
| 本地可读 | 授权投影与文件引用原子提交且本地打开成功 | 整场节目单、共享冻结及所有页均准备好 |
| 演出准备完成 | 对明确节目单/版本/权限基线完成整场检查，个人层和冻结共享层可读，无未保存修改 | 离线即时撤权已解决、后续更新可热替换、真机长期可靠性已通过 |

上述状态绑定账号/设备/revision，界面要显示时间和失败原因。管理员“全员准备完成”须按当前动态参与成员及所需设备集合计算，不固定七台或七人。

## 2026-10-13 新决定对应的接口与验收增量

- 撤权与在演会话分开：普通授权 tombstone 立即生效；已开始的冻结 performanceRun 仅允许继续读取该场次已经准备好的固定清单，不授予新下载/新曲目/新入场权限。退出时终结该 run；旧 cursor、重新登录和旧快照不能创建同等例外。如何判定后台/进程中断后的 run 连续性、凭据期限仍待定义，不能默认为永久有效。
- 私人备份分离 preference 与 consent：默认提供开启选项不代表已获上传同意。用户最终已选择注册时一次提醒：注册流程清晰说明并确认“批注自动备份到团队 NAS，管理员可阅读”；既有账号首次启用补同等一次说明确认。确认后自动同步，不逐次弹窗、不常驻主界面提示；设置可查备份状态与管理员读权。以下字段为后续实现契约，本批不实际上传。上传接口须同时验证本人身份、团队、当前授权及 consentVersion/consentAt；未确认返回 CONSENT_REQUIRED，客户端保持本地笔画，不静默清除或上传。
- 管理员读取使用明确的团队范围及成员/源版本/源页请求；服务端核验管理员当前角色和 teamId，不信任客户端传入角色。记录访问与导出审计；普通成员猜 ownerId、其他团队管理员猜 artifactId/annotationId 仍拒绝。
- “管理员可阅读”不自动开放母库 ZIP 混入全部私人层、任意导出、密钥托管或无限保留。对应备份恢复/取回细则及成员撤回同意后的已有数据处置，在实现前补齐。
